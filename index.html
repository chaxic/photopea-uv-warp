How this workflow works
  1. Convert the image to a Smart Object and select it.
  2. Capture it, then arrange the mesh in Layout mode over the source.
  3. Switch to Warp and move matching points onto the reference underneath.
  4. Use Preview to compare live, then create the output.

The result and mesh data are saved in the PSD. Choose the saved warp above to edit and update it later.
