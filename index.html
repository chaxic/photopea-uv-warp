How this workflow works
  1. Select a Smart Object and Capture selected (source only).
  2. Optionally Capture reference or load an alignment image.
  3. In Layout, use the Pen tool like RetopoFlow PolyPen: extrude edges, grow tris/quads, and bridge two edges to fill gaps.
  4. Switch to Warp, move matching points onto the reference, then Create output.

Output adds a UV Warp Result layer and a hidden UV Warp Data layer. The original source stays in the PSD untouched — use On / off to show it again, or Edit a saved warp to tweak and update the result.
