How this workflow works
  1. Select a layer and Capture selected under Source — only that layer is captured.
  2. Optionally select another layer and Capture selected under Reference, or load an image. Use Reference tint if the images look too similar.
  3. In Layout, use Draw in Face mode to close triangles/quads into faces (hold Ctrl or switch to Line for knife-only cuts). Select can pick points, lines, or faces, or drag a marquee; Del removes the selection while keeping points when deleting faces/lines.
  4. Switch to Warp, move matching points onto the reference, then Create output.
Output layers & editing later

Create output renames your source and adds a group like this:

building1-3 [Original]          ← your source (hidden, not modified)
UV Warp · building1-3 [UVWP:id]
├─ building1-3 [Warped]         ← the visible result
└─ Mesh Data — do not edit [id] ← hidden plugin data
  • … [Original] — your source layer with [Original] appended. Content is unchanged; only the name and visibility change. Use On / off to show it again.
  • … [Warped] — the warped image. Safe to show, hide, or move within the group.
  • Mesh Data — do not edit — stores the mesh and which layer was used as the reference, so you can reopen this warp. Keep it hidden. Do not edit its text, rename it, or delete it if you want to edit later.
  • UVWP:id in the group name — leave it alone. The plugin uses it to find this warp.

To edit a finished warp: open this panel → pick the warp under Saved warp → Edit. The source loads, and a captured reference layer is re-captured from the PSD automatically → adjust Layout/Warp → Create output again to update the Warped layer.

A reference added with Load image is not stored in the PSD, so load that file again after editing.
